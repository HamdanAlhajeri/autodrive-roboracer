## Run and rollback

```powershell
.\record-one-lap.ps1 -Laps 3 -Label planned-3p0-a1p5 -NoTrackMap
```

Reset when prompted. The script reloads both controller and actuator settings.
`-NoTrackMap` avoids rebuilding the already available LiDAR outline while racing;
the saved runtime map and planned-path graph remain available.

An optional `-ResetSimulator` flag now sends the simulator reset command and
confirms fresh stationary odometry plus zero lap/collision counters before
starting. Failure to confirm reset aborts startup. It is simulator-specific.
